Upload and enforcement

Safety parameters can be edited below. Saving them and uploading boundaries are separate operations.

Changing fences requires the aircraft to be disarmed. Enabling requires a fresh 3D GPS fix. Upload replaces existing fence boundaries. Existing altitude limits, home radius, breach action and inclusion-combination settings remain in effect.

ArduPilot recommends a minimum fence radius of 30 m. Very small GPS fences can breach because of position drift. Fence guidance

Speed and safety settings

Live controller values with parameter names and units. Only supported parameters become editable. Navigation speeds apply to relevant navigation modes, not every flight mode. The 2 m flight script temporarily sets horizontal speed to 0.2 m/s and climb speed to 0.15 m/s, then restores saved values after landing.

Vertical fences use the selected altitude reference. Minimum altitude activates after reaching that height and may be disabled during landing. Terrain reference requires valid terrain data. Saving parameters leaves fence enforcement disabled; enable it separately.

Replace the controller fence?

The aircraft must be disarmed and fence enforcement disabled. The existing boundaries will be backed up on the Pi before upload. The new fence is accepted only after controller readback matches.

Save controller settings?

The aircraft must be disarmed and enforcement disabled. Previous values will be backed up on the Pi. Changes are applied individually and read back; a failure can leave earlier changes saved.
